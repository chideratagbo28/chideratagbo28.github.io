Featured Projects

MSc Dissertation, 2026
Web Honeypot System with AI-Driven Intrusion Detection
✓ Completed

Designed and deployed a multi-sensor T-Pot honeypot on Oracle Cloud Free Tier (UK South), capturing approximately 4 million real attack events across 8 active sensors. Attack telemetry was analysed for threat intelligence, mapped to the MITRE ATT&CK framework, and used to train a two-classifier AI system that identified why existing detection tools miss modern attacks and demonstrated how to fix it. A confidence-thresholded prevention layer (Block / Review / Allow) was implemented alongside an interactive Streamlit demonstration interface.

⚠ Principal Finding
A Random Forest classifier achieving 97% accuracy on the CSIC 2010 benchmark failed to assign the correct attack-type label to a single one of 397 real honeypot-captured web attacks, showing that high accuracy on test data does not mean the system will detect real attacks. 📋 Governance and Documentation The project was managed as a structured governance deliverable alongside the technical build. An evidence register was maintained throughout, all findings were validated against source data before recording, and outputs included an ISO 27001-aligned risk-rated assessment report. The OpenAI API was integrated to generate AI-augmented plain-English prevention recommendations, reducing manual drafting effort. A Streamlit interface was built to present findings clearly to a non-technical audience, functioning as a structured knowledge repository.
